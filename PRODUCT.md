# Files

## Register

product

## Users and purpose

Lucas uses BB on a desktop and through remote views to move between code, images, and video while talking to agents. Files keeps that activity next to the conversation. Success means reaching a known path immediately, seeing what is there, inspecting a file, and selecting paths for a draft without leaving the thread.

## Direction

Compact, familiar, direct. Pikeru provides the reference for useful thumbnails and recognizable file types. A writable path bar is the primary navigation affordance; search and bookmarks are additional conveniences. Directory columns supplement list and grid views.

## Principles

- Start in the thread workspace and show the machine explicitly.
- Keep the basic navigation path available even when helper features fail.
- Prefer previews and real file metadata over explanatory product copy.
- Make keyboard and pointer navigation equivalent.
- Keep filesystem reads and media buffering bounded.
- Video reliability matters more than reusing BB's built-in player loader.

## Accessibility

Labeled controls, listbox selection semantics, keyboard navigation, focus indication, and reduced-motion support. These are implementation defaults rather than a claim of completed WCAG certification.
